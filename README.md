# Flux Engine

An incremental game about tiered Engines, prestige layers and Heat. Plays on desktop and phones, and you can add it to your home screen.

**Play:** https://dlswimmer.github.io/flux-engine/

```
npm install
npm run dev        # http://localhost:5173  (add ?dev for game-speed controls)
npm run sim        # pacing / strategy sweep
npm run playtest   # feel, upgrade values, automation vs holding M
```

Design notes, balance rules and the roadmap are in [DESIGN.md](DESIGN.md).
